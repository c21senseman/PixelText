# PixelText

PixelText는 경계 없는 2차원 셀 공간에 문자를 배치하는 Canvas 기반 텍스트 편집기입니다. 한글 IME와 이모지 문자소 묶음을 지원하며, 문서는 브라우저의 IndexedDB에 자동 저장됩니다.

## 주요 기능

- 64×64 희소 청크 기반 무한 문자 캔버스
- 저장하지 않는 빈칸과 문자 사이 한 칸 공백 구분
- Insert 전환 삽입·덮어쓰기 편집, Enter 줄 분리, Backspace/Delete 당김
- 사각형 선택, 경계 조절과 자동 줄바꿈, 복사·붙여넣기, 드래그 진입 방향 또는 방향키를 따르는 가로·세로 밀기와 덮어쓰기 이동
- 실행 취소·다시 실행, 전체 검색, 책갈피, 미니맵
- 브라우저별 자동 저장과 JSON/TXT 가져오기·내보내기
- 큰 양수·음수 좌표 및 5%–400% 확대 지원

## 로컬 실행

```bash
npm install
npm run dev
```

## 단일 HTML 빌드

```bash
npm run build
```

빌드 결과는 `dist/index.html` 하나입니다. 스타일, React 런타임, 편집기 코드와
아이콘이 모두 문서 안에 포함되므로 별도 서버나 정적 자산 없이 파일 하나만
배포하거나 오프라인에서 열 수 있습니다.

편집 엔진 테스트는 `npm test`, 타입 검사는 `npm run typecheck`, 정적 검사는
`npm run lint`로 실행합니다.
